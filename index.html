О себе

Меня зовут Юлия. Я окончила колледж по направлению "Программирование в КС" и университет по специальности "Программная инженерия". В данный момент работаю в Сбербанке (отдел безопасности, ТСО), но активно развиваюсь в веб-разработке. Моя цель — углубить и структурировать свои знания во фронтенде, научиться создавать качественные, адаптивные интерфейсы и применять свой инженерный бэкграунд для решения реальных задач в коммерческой разработке.

Мои Навыки

Ничего не найдено.

HTML

Определяет структуру и содержание веб-документов с помощью специальных элементов — тегов

CSS

Позволяет управлять оформлением HTML-элементов: задавать цвета, шрифты, размеры, отступы, расположение блоков, тени, градиенты и другие визуальные аспекты.

JavaScript

Предназначен преимущественно для создания динамических и интерактивных веб-страниц. С его помощью добавляют на сайты интерактивные элементы: анимации, всплывающие окна, формы обратной связи, кнопки лайков, калькуляторы и другие.

C#

Объектно-ориентированный язык программирования, созданный компанией Microsoft в рамках её .NET Framework и .NET Core/5+. Он сочетает элементы современных и традиционных языков, обеспечивая высокую производительность, безопасность и интеграцию с экосистемой Microsoft.

Git

Распределённая система управления версиями (Version Control System, VCS), которая позволяет отслеживать изменения в файлах проекта, сохранять их историю и возвращаться к предыдущим версиям.
